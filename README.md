# Hex WorldMaker — ออกแบบแผนที่แฟนตาซี

เว็บแอปออกแบบแผนที่แฟนตาซีแบบ Hexagon Map รองรับการจำลองภูมิศาสตร์จริงและการส่งออกไฟล์

- **GitHub Pages:** https://pasawud.github.io/World_maker/

## ความสามารถหลัก
- **แผนที่หกเหลี่ยมประสิทธิภาพสูง**: เรนเดอร์แบบแบ่ง Chunk ซูม-แพนลื่นไหล พร้อม Minimap และสเกลระยะทางจริง (`กม.`)
- **ภูมิศาสตร์จริง & แม่น้ำอัตโนมัติ**: จำลองอุณหภูมิตามละติจูด/ความสูง, ทิศทางลมประจำถิ่น + เงาฝน (Rain Shadow), และระบบ Priority-Flood วางสายน้ำไหลลงสู่ทะเล
- **ไบโอม ลักษณะพิเศษ & Custom**: ไบโอมพื้นฐาน 16 แบบ, ลักษณะพิเศษ 20 แบบ (โอเอซิส, ปะการัง, ฟยอร์ด, หุบผาชัน ฯลฯ) และสร้างไบโอม/สถานที่น่าสนใจเองได้
- **การปกครอง ศาสนา เมือง & การค้า**: วางเมือง, สินค้าผลิต/นำเข้า, อาณาจักรพร้อมระบอบการปกครอง, เขตศาสนา, ถนนอ้อมภูเขา/ทางเดินเรือ และเส้นทางการค้า A*
- **นำเข้า / ส่งออก**: บันทึกอัตโนมัติในเบราว์เซอร์, ส่งออก/โหลด `.hexworld.json`, และส่งออกภาพ `.png`

## การรันบนเครื่อง
```powershell
npm.cmd install
npm.cmd run dev
```
